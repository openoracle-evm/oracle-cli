# Contributing to oracle-cli

Thanks for helping improve Open Oracle. Issues and pull requests are welcome.

## Setup

```bash
git clone https://github.com/openoracle-evm/oracle-cli
cd oracle-cli
npm install
```

## Before you open a pull request

1. Run `npm run build` and `npm test`. CI runs the same commands.
2. Keep changes focused. One feature or fix per pull request.
3. Add or update tests for any behaviour you change.
4. Update `CHANGELOG.md` under **Unreleased**.

## Reporting bugs

Open an issue with the steps to reproduce, what you expected and what happened. For security problems, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
